# Project Liger Zero

Written in Swift, Liger Zero is a prototype life simulation game based on [Motive Engine](https://github.com/tonytins/motive-engine), the AI library, and a future game engine.

## 🧰 Minimum Requirements

### Development

- Swift 6.3+

### Deployment

| Target  | Version | 
| ------- | ------- | 
| macOS   | 10.13   | 
| Windows | 10      | 
| Ubuntu  | 20.04   | 
| Debian  | 12      | 
| Fedora  | 39      |
